## Goal
The client subscribes only to the 3×3 sector window around its predicted position, re-subscribes on sector change with hysteresis, and reconciles rather than reloading. Whole-table subscriptions from P0 are gone.

## Definition of done
- [ ] Subscription manager swaps window queries on sector change and debounces border jitter
- [ ] Rows leaving the window are dropped from the snapshot; entering rows appear without a flash
- [ ] Measured bytes/s per client while walking through a busy synthetic sector ≤ 20 KB/s (3.9), with the method in PR
- [ ] Reconnect path (P0-016) re-subscribes to the current window (test)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally
