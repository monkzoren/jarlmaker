## Goal
Real tiles replace placeholders for the six biomes: base ground variants, water edge, cliff, and the feature sprites the generator places (trees, rocks, ore).

## Definition of done
- [ ] Every tileset id referenced by `content/biomes` has agent-drawn text pixel sources that pack cleanly (`pnpm atlas` green)

- [ ] Contact-sheet previews (`pnpm atlas --preview`) and an in-client screenshot of each biome attached to the PR
- [ ] Tiles use only the locked palette and read clearly at 2× on a phone screenshot
