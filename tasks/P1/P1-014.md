## Goal
Terrain is drawn from the same pure `cellAt` the server uses (no base terrain on the wire). Each chunk is pre-rendered once to a render texture and re-rendered only when a `cell_delta` for it arrives.

## Definition of done
- [ ] Visible-chunk window around the camera with an LRU texture cache and bounded memory
- [ ] Invalidate and re-render exactly the chunk named by a `cell_delta` update
- [ ] Draw calls for terrain ≤ number of visible chunks (perf overlay screenshot)
- [ ] No per-frame allocation in the chunk path (perf overlay allocation counter flat while walking)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally
