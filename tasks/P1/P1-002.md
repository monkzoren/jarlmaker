## Goal
Integer-hash-based 2D noise that gives bit-identical results in Node, V8-in-SpacetimeDB and every browser, the foundation for the field stack.

## Definition of done
- [ ] Seeded integer hash (no `Math.random`, no platform trig inside hashing)
- [ ] Value or simplex noise, fbm, ridged, and domain-warp helpers, all pure `(seed, x, y) → number`
- [ ] Golden-value test: 64 fixed samples per function committed as literals in the test
- [ ] Throughput benchmark in PR (samples/ms)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally
- [ ] Reviewer checks: no file over 600 lines, no numeric literal other than 0/1/-1 in `rules.ts`/`tick.ts`, no store scan, nothing imported from `server`/`client`

## Notes
Float determinism: prefer arithmetic that is exact in IEEE-754 doubles across engines, and avoid `Math.sin`/`Math.exp` in anything that feeds a cell decision.
