## Goal
The server side of sector-based interest management (3.6.1): spatial tables are indexed by sector, and chunks materialise when a player first enters their sector. Each tick logs per-system milliseconds.

## Definition of done
- [ ] `entity_pos.sector` and `cell_delta.sector` indexed in the generated tables (`pnpm gen:tables`)
- [ ] The `entity.sector_changed` handler materialises chunks in the new 3×3 window once
- [ ] `tick_perf` table: per-system ms for the last N ticks (ring buffer by slot, no growth)
- [ ] Documented subscription queries in `packages/server/README.md` (one per spatial table, `WHERE sector IN (…)`)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
Row-level visibility is not needed yet, and parties/chat come in P6.
