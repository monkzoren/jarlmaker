## Goal
The player is a drawn Viking castaway, not a still placeholder. There are 4 facings (down, up, side, with left mirrored from right), a 4-frame walk cycle and an idle frame, and a soft ground shadow. The walk frame advances with the distance walked, so the feet never skate. Your own sprite and remote players animate the same way, and nearer sprites draw over farther ones. The maintainer's first playtest asked for this directly: "We 100% need walk animation and directional sprites."

## Definition of done
- [x] `art/` workspace package `@bastion/art`: text pixel source `art/characters/castaway.ts` (16×32, palette-indexed, `idle` and `walk` for `down`/`up`/`side`) plus a test for frame size, palette keys and complete directions
- [x] `packages/client/src/render/animation.ts`: a pure animator that picks direction and flip from drawn motion (diagonals show the side view), is idle when still, and advances the walk frame by distance. Unit-tested
- [x] `scene.ts` draws each entity from the castaway frames with a shadow, sorted by y; the placeholder grid is removed
- [x] Contact sheet and an in-game screenshot of walking attached to the PR
- [x] `pnpm build lint test replay smoke tasks:validate` green
