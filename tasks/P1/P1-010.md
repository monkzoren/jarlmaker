## Goal
The art pipeline: one locked 64-colour palette, and `pnpm atlas` packing source sprites into atlases + JSON + animation JSON, rejecting any off-palette pixel (3.5.9).

## Definition of done
- [ ] `art/palette.gpl` with 64 colours including sea-grey, pine-green and ember-orange ramps (3.0 Branding)
- [ ] `pnpm atlas` packs PNG (and `.aseprite` via a JS parser, so CI needs no Aseprite install) into per-category atlases with frame and animation JSON (`idle, walk, attack, hit, die` @ 8 fps)
- [ ] An off-palette pixel fails with file, frame, x, y and colour
- [ ] `--placeholder` generates flat palette-coloured tiles for every tileset id referenced by content, so rendering never waits on art
- [ ] Tests for packing, palette rejection and animation JSON
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally
