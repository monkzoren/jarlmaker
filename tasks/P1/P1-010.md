## Goal
The art pipeline: one locked 64-colour palette, and `pnpm atlas` packing source sprites into atlases + JSON + animation JSON, rejecting any off-palette pixel (3.5.9).

## Definition of done
- [ ] `art/palette.gpl` with 64 colours including sea-grey, pine-green and ember-orange ramps (3.0 Branding)
- [ ] Text pixel source format (ADR 0007): palette-indexed character grids with a legend, frame blocks and animation tags; documented in `art/README.md` with a worked example
- [ ] `pnpm atlas` packs text sources (primary) and PNG/`.aseprite` (secondary, via a JS parser, so CI needs no Aseprite install) into per-category atlases with frame and animation JSON (`idle, walk, attack, hit, die` @ 8 fps)
- [ ] `pnpm atlas --preview <src>` renders a scaled PNG contact sheet so reviewers can judge the art itself, not its text
- [ ] An off-palette pixel fails with file, frame, x, y and colour
- [ ] `--placeholder` generates flat palette-coloured tiles for every tileset id referenced by content, so rendering never waits on art
- [ ] Tests for packing, palette rejection and animation JSON
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
The agents draw the art (ADR 0007), so the text format is the main authoring surface. Make it pleasant to write by hand: short legend keys, a comment syntax, and mirroring helpers for 4-direction sprites.
