## Goal
The workspace root runs every Section 3.8 check through Turborepo: `pnpm build`, `lint`, `test`, `contentlint`, `balance`, `replay`, `smoke`, `worldgold`. Checks with nothing to run yet pass trivially and say so, so later tasks only have to fill them in.

## Definition of done
- [ ] `turbo` pinned to an exact version in root `devDependencies`, and `turbo.json` defines `build`, `typecheck`, `lint`, `test` with correct `dependsOn`/`outputs`
- [ ] Root scripts `build`, `lint`, `test`, `typecheck`, `contentlint`, `balance`, `replay`, `smoke`, `worldgold` exist; each not-yet-implemented one exits 0 and prints `<name>: no checks yet`
- [ ] TypeScript pinned to exactly `5.9.3` at the root (typescript-eslint supports <6.1; see ADR 0004 item 6)
- [ ] The existing `tasks:*` scripts still work (`pnpm tasks:validate` passes)
- [ ] `pnpm install --frozen-lockfile && pnpm build && pnpm test` passes from a clean clone
- [ ] `pnpm -r typecheck` and `pnpm -r test` green locally (lint and turbo may not exist yet)
