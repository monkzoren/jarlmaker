## Goal
`MemoryStore` is a fixture that is never shipped (CLAUDE.md 3.4). P0-023 moved it behind a separate `@bastion/core/testing` entry, but nothing enforces that shipped code stays off it. After this task, `pnpm lint` fails if non-test source in `packages/client`, `packages/server` or `packages/commerce` imports `@bastion/core/testing`.

## Definition of done
- [ ] `eslint.config.js` applies `@bastion/layering` (or an equivalent rule) with `@bastion/core/testing` forbidden to `packages/{client,server,commerce}/src/**`, excluding `*.test.ts`
- [ ] A RuleTester case in `tools/eslint-plugin` rejects `import { MemoryStore } from '@bastion/core/testing'` under that config and accepts `import { tick } from '@bastion/core'`
- [ ] `pnpm lint` and `pnpm -r test` green

## Notes
`layering` already takes a `forbidden` list of bare module names (exact match or subpath), so `'@bastion/core/testing'` blocks the testing entry without blocking `@bastion/core`.
