## Goal
Recorded command scripts run through `core` on `MemoryStore`, and the resulting store and event sequence are compared to committed goldens. This is the regression net for every rule, and the reference the smoke test diffs the server against.

## Definition of done
- [x] Script format (JSON): seed, content hash, and a list of `{atTick, sender, envelope}`; ticks advanced between commands
- [x] `pnpm replay` runs every `tests/replay/*.json` and compares against `*.golden.json` (store dump sorted by table/pk + event list)
- [x] `pnpm replay --update` rewrites goldens and prints a summary diff
- [x] First script `walk-square.json`: join, then move in a square, and the golden is committed
- [x] A test proves a changed rule makes replay fail with a readable diff
- [x] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
Keep the store dump format stable and human-diffable. The smoke test (P0-018) will dump the server in the same format.
