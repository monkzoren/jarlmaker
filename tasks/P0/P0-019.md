## Goal
One `BUILD_ID` (git short SHA + UTC build time) is stamped by the build into the client bundle and the module, so no human or agent ever edits a version number (3.6.6, wound "hand-bumped version lockstep").

## Definition of done
- [x] `tools/build-id` computes the id once per build; both packages read it (Vite `define`, generated server const, git-ignored)
- [x] Client shows the id in the perf/debug corner; a server reducer or view exposes the module's id
- [x] Grep in PR shows no hand-written version string anywhere in the repo besides `package.json` package versions (which stay `0.0.0`)
- [x] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
The `compat` table (minimum client build) is P6. The service worker gets the id when the PWA lands (P6).
