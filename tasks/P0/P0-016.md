## Goal
Dropouts are a feature (3.6.7): the client keeps rendering, shows a quiet pip, queues commands for up to the tuning window, reconnects with backoff, replays the queue in nonce order, and reconciles its snapshot without a reload. Past the window it drops the queue and shows a toast.

## Definition of done
- [ ] Connection state machine (`online → dropped → reconnecting → online`) with unit tests over a fake transport
- [ ] Queue bound and window come from `content/tuning/net.ts`; oldest-first replay; server dedupe makes a duplicate replay harmless (test)
- [ ] Subscriptions re-established after reconnect; the snapshot is reconciled, and the page is never reloaded
- [ ] Reconnecting pip and drop toast use text/CSS (no emoji); they appear only in the matching states
- [ ] Manual check in PR: kill the socket in devtools for 10 s while walking, and the walk lands after reconnect
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally
