## Goal
The client can import command payload types and rules from `@bastion/core`,
and its unit tests can opt into a DOM with jsdom. P0-014 (input) needs both
and its `touches` cannot reach `packages/client/package.json`. P0-013 and
P0-015 (net, prediction) need the core dependency too.

## Definition of done
- [x] `packages/client/package.json` lists `"@bastion/core": "workspace:*"` under `dependencies` and a pinned `jsdom` under `devDependencies`; `pnpm-lock.yaml` regenerated by `pnpm install`
- [x] `packages/client/vite.config.ts` keeps `environment: 'node'` as the default, with a comment saying a test opts into a DOM with a `// @vitest-environment jsdom` docblock
- [x] `pnpm --filter @bastion/client typecheck` resolves `import type { CommandRegistry } from '@bastion/core'`
- [x] `pnpm build`, `pnpm lint`, `pnpm test` green locally
