## Goal
Every PR runs the full Section 3.8 check list plus `pnpm tasks:validate`, and merging is gated on it. Pushes to `main` regenerate `docs/BOARD.md` and `docs/STATUS.md` and commit them.

## Definition of done
- [ ] `.github/workflows/ci.yml` runs, on PRs and on `main`: install with pnpm cache, `build`, `lint`, `test`, `contentlint`, `balance`, `replay`, `worldgold`, `tasks:validate`
- [ ] A separate `smoke` job exists with Docker available; it runs `pnpm smoke` (a placeholder until P0-018)
- [ ] On `main` only: `pnpm tasks:board && pnpm tasks:status` with `fetch-depth: 0`, committed back as `chore(tasks): regenerate board [skip ci]` only when changed (`contents: write` permission)
- [ ] Node version comes from `.nvmrc`, and pnpm from `packageManager`
- [ ] The workflow is green on the PR that adds it (link the run in the PR)
- [ ] README or PR body tells the maintainer to mark the `ci` checks as required in branch protection

## Notes
ADR 0003: PRs never commit the board. Only this job does, so parallel PRs never conflict on it. If branch protection blocks the bot push, the job should fall back to uploading the board as an artifact and say so in the log.
