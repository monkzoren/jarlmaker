## Goal
The local player moves instantly by running the same `core` `step` on its unacknowledged inputs, and reconciles to the server row when it arrives by replaying pending inputs on top of the authoritative position. Remote entities are interpolated.

## Definition of done
- [x] Input sink wired: every input is sent as a `move` reducer call and kept in a pending buffer until the server reflects it
- [x] Prediction calls the `step` function imported from `@bastion/core`; the client contains no movement math of its own (reviewer greps for it)
- [x] Reconciliation: on a server update, reset to the server state and re-apply pending inputs; the correction is smoothed visually and never in the sim
- [x] Remote entities are interpolated with a fixed render delay
- [x] A unit test with a fake server shows zero divergence for an identical input stream
- [x] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
ADR 0001: prediction is the only simulation on the client, and it must be the same function the server runs.
