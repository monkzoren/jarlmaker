## Goal
A SpacetimeDB 2.x TypeScript module package that publishes to a local SpacetimeDB running in Docker, with one hello table and one reducer. It proves the toolchain end to end before any game code depends on it.

## Definition of done
- [x] `spacetimedb` npm package and the Docker image pinned to the same exact 2.x version (current stable when the task starts; record it)
- [x] `docker-compose.yml` starts SpacetimeDB on a fixed local port with a named volume
- [x] Scripts: `pnpm server:up`, `pnpm server:publish` (local, `--clear` allowed), `pnpm server:bindings` (generates client bindings into `packages/client/src/net/bindings`)
- [x] Hello module: one table + one reducer; the PR shows the transcript of publish, call, and SQL query result
- [x] `docs/DECISIONS/0006-spacetimedb-version.md` records the pinned version and the upgrade rule
- [x] `pnpm -r typecheck` and `pnpm -r test` green locally (lint and turbo may not exist yet)

## Notes
On 2026-09-27, npm `spacetimedb` latest was 2.10.1. Use whatever is current, pin it, and record it. The hello table is deleted in P0-011.
