## Goal
The Phase 0 promise, automated: a browser connects to a fresh SpacetimeDB in Docker, walks, loses its socket for 10 s mid-walk, reconnects, and the server store matches the replay golden for the same command script.

## Definition of done
- [ ] `pnpm smoke` starts a throwaway SpacetimeDB container, publishes the module, serves the client, runs Playwright, and tears it all down
- [ ] Scenario `walk-and-drop`: connect, join, scripted input, socket blocked 10 s (routing or CDP offline), unblocked, input landed
- [ ] After the run the server tables are dumped in the replay format and diffed against the matching replay golden
- [ ] CI `smoke` job runs it (replacing the placeholder) and uploads traces on failure
- [ ] Runs green twice in a row locally and in CI (links in PR)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
Use `executablePath: /opt/pw-browsers/chromium` in cloud sessions if the pinned Playwright version differs. Never run `playwright install` there.
