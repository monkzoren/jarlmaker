## Goal
`content.tuning.net` (`tickHz`, `reconnectQueueSeconds`, `reconnectQueueMax`) is validated by a Zod schema registered in core, so `createGame(content)` keeps it and hosts read it as `game.content.tuning.net`. Today no system registers `net`, so `createGame` drops it as unvalidated and the server's `tick.ts` reads `tickHz` straight from `@bastion/content` with a hand guard.

## Definition of done
- [ ] `registerTuning('net', netTuning)` in `packages/core/src/kernel/` (tickHz positive, queue knobs positive ints) with the `TuningRegistry` merge
- [ ] A test: `createGame(content).content.tuning.net.tickHz === 10`, and a non-positive `tickHz` throws `ContentError`
- [ ] `packages/server/src/tick.ts` reads `game.content.tuning.net.tickHz` and drops its direct `@bastion/content` read and hand guard
- [ ] `pnpm build lint test tasks:validate` green
