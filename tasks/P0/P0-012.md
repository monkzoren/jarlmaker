## Goal
The client package serves a page that renders one 16×32 placeholder sprite on a PixiJS v8 stage at an integer zoom picked from device pixel ratio, with `roundPixels` on. This is the render shell that the net and input tasks plug into.

## Definition of done
- [ ] `pixi.js` pinned to an exact v8 version; Vite dev server via `pnpm --filter @bastion/client dev`
- [ ] Integer zoom 2×/3×/4× chosen from `devicePixelRatio` and viewport; `roundPixels: true`; nearest-neighbour scaling
- [ ] Placeholder sprite drawn from a generated texture (no image asset needed yet, no emoji anywhere)
- [ ] `render/` exposes `setEntities(snapshot)` so net code never touches Pixi directly
- [ ] Page renders in Chromium via Playwright screenshot attached to the PR
- [ ] `pnpm -r typecheck` and `pnpm -r test` green locally (lint and turbo may not exist yet)

## Notes
No game rules in the client (ADR 0001). Keep `app.ts` as the wiring point only.
