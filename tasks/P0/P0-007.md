## Goal
`@bastion/content` exists as typed data only (no functions), with `tuning/` holding the first knobs (movement speed, sector size, tick rate, reconnect queue). `pnpm contentlint` validates the whole content set through core's schemas and cross-reference checks.

## Definition of done
- [ ] `packages/content` depends on `@bastion/core` for types only (`import type`), and exports one `content` object
- [ ] `tuning/movement.ts`, `tuning/world.ts` (sector size in cells), `tuning/net.ts` (tick Hz = 10, reconnect queue 30 s), each knob with an intent comment
- [ ] `tools/contentlint` loads `@bastion/content`, runs `core`'s `loadContent` validator, and exits non-zero with a readable path on failure
- [ ] A test proves contentlint rejects a deliberately broken fixture
- [ ] Root `pnpm contentlint` runs it (replacing the P0-001 placeholder)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally
