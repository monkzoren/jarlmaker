## Goal
The server is the game host (ADR 0001): `StdbStore` implements `Store` over `ctx.db`, each reducer is 5–15 lines that parses, builds the store, calls `core.execute` with `ctx.sender`, and throws on rejection. A scheduled reducer calls `core.tick` at the tuning tick rate.

## Definition of done
- [x] `store.ts`: `StdbStore` maps `get`/`byIndex`/`insert`/`update`/`delete` to generated table handles; `now()` = `ctx.timestamp`, `rng()` = `ctx.random` (or a seeded PRNG from it)
- [x] Events emitted during a reducer are dispatched in-transaction via core; no event table yet
- [x] Reducers `join` and `move`, one file each under `src/reducers/`, each ≤ 15 lines
- [x] `tick.ts`: scheduled reducer at 10 Hz calling `core.tick`; authority checks prevent clients calling it
- [x] Hello table and reducer from P0-010 removed
- [x] Manual verification transcript in PR: publish, call `join` + `move` via CLI, query `entity_pos` shows movement
- [x] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
If `ctx.random` is unavailable in the pinned version, seed the core PRNG from `ctx.timestamp` + a server-held seed row, and write that down in the store README.
