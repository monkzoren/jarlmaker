## Goal
Keyboard (WASD/arrows) and a touch virtual stick produce `entity.move` input vectors, sampled at the tick rate and emitted to a `CommandSink` interface with monotonically increasing nonces.

## Definition of done
- [ ] `input/` exports `createInput(sink)`; `CommandSink` is an interface declared in `input/types.ts`
- [ ] Keyboard and touch stick map onto the same `entity.move` payload type imported from `@bastion/core`
- [ ] Nonces are monotonic per session and survive a reconnect (persisted in `sessionStorage`)
- [ ] Unit tests for vector normalisation, dead zone, and nonce monotonicity (jsdom)
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
Wiring the sink to the network is P0-015. Gamepad support comes later (3.5.10).
