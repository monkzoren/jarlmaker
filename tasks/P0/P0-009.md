## Goal
Table shapes are declared once in `core` (3.4). `pnpm gen:tables` writes `packages/server/src/tables.ts` (SpacetimeDB table definitions with the same columns, pk and indexes), and a test fails when the committed file drifts from the generator's output.

## Definition of done
- [ ] `tools/gen-tables` maps each Zod column type used by core tables to its SpacetimeDB 2.x column type; an unsupported type fails generation with the column path
- [ ] Generated file carries a "generated — do not edit" header and is deterministic (stable ordering)
- [ ] Drift test (`pnpm test`) regenerates in memory and diffs against the committed file
- [ ] `pnpm build` runs `gen:tables --check`
- [ ] `pnpm build`, `pnpm lint`, `pnpm test` green locally

## Notes
MemoryStore reads the declarations at runtime and needs no generation. Only the server needs generated code. Append-only rule (3.4): the generator should fail if a column present in the committed file disappears or changes type.
