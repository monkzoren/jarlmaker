## Goal
A contributor runs `pnpm server:up`, `pnpm server:down`, `pnpm server:publish`, `pnpm server:bindings` and `pnpm server:cli` from the repo root, not only from `packages/server`.

## Definition of done
- [ ] Root `package.json` scripts `server:up`, `server:down`, `server:publish`, `server:bindings`, `server:cli` each forward to `pnpm --filter @bastion/server <same name>`
- [ ] `pnpm server:up && pnpm server:publish` run from the repo root publishes the module (transcript in the PR)
- [ ] `pnpm tasks:validate` passes

## Notes
P0-010 put the scripts in `packages/server/package.json` because the root `package.json` is outside its `touches` (it belongs to lane `repo`, P0-001). See ADR 0006 for how the scripts resolve the pinned CLI.
