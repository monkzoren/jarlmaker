## Goal
`MemoryStore` implements `Store` over in-memory maps with real secondary indexes, a seeded deterministic PRNG, a controllable clock and an inspectable event log. This is the host for unit tests, replay, balance and the quest solver (ADR 0001).

## Definition of done
- [x] `MemoryStore` implements every `Store` method; `byIndex` is served from maintained index maps, never by filtering all rows
- [x] `insert` on an existing pk and `update`/`delete` on a missing pk throw
- [x] `rng.ts`: a small seeded PRNG (e.g. sfc32) with `next()`, `int(lo, hi)`, `pick()`; same seed gives the same sequence (golden test)
- [x] Clock: `now()` returns a settable timestamp; `advance(ms)` helper for tests
- [x] `emit` appends to an event log readable as `store.events()` and clearable
- [x] Unit tests cover index maintenance across insert/update/delete of an indexed column
- [x] Bench note in PR: 100k inserts + 100k `byIndex` lookups timing (no assertion yet)
- [x] `pnpm -r typecheck` and `pnpm -r test` green locally (lint and turbo may not exist yet)
- [x] Reviewer checks: no file over 600 lines, no numeric literal other than 0/1/-1 in `rules.ts`/`tick.ts`, no store scan, nothing imported from `server`/`client`
