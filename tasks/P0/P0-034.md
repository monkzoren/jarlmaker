## Goal
The client input knobs have a home in tuning (CLAUDE.md 3.1 pillar 3): `content/tuning/input.ts` exports an `input` section with `deadZone` (fraction of the stick radius that reads as zero) and `stickRadiusPx` (CSS px of full deflection), each with a comment on intent. `createInput` (P0-014) takes these as options; P0-015 wires them in `app.ts` alongside `net.tickHz`.

## Definition of done
- [ ] `packages/content/tuning/input.ts` exports `input = { deadZone, stickRadiusPx }` with an intent comment per knob
- [ ] `tuning/index.ts` re-exports `input`
- [ ] `0 <= deadZone < 1` and `stickRadiusPx > 0` checked by a schema or a content test
- [ ] `pnpm build lint test tasks:validate` green
