## Goal
Anyone who ran the local server before P0-044 has a database owned by an identity signed with the old container-local key. After P0-044, `pnpm server:publish` fails with `… is not authorized to perform action on database …: reset database`, even after `pnpm server:cli logout`. README Troubleshooting explains the one-time fix.

## Definition of done
- [ ] README Troubleshooting has an entry quoting the `not authorized to perform action on database` error, with the fix: `pnpm server:down && docker volume rm bastion_bastion-stdb && pnpm server:up && pnpm server:cli logout && pnpm server:publish`. It notes this wipes local data and only happens once, after upgrading past P0-044.
- [ ] The fix was verified by reproducing it: an old-key volume, then publish fails, then the commands above, then publish succeeds (transcript in the PR)
- [ ] `pnpm tasks:validate` green
