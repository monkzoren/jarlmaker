# Playtest feedback

The maintainer plays each phase build for 20 minutes at its gate and writes
notes here, under the phase's heading. A phase's exit task cannot be `done`
without its entry. The Planner folds each point into a task, quoting the
feedback in that task's Notes. Feedback is a design brief, not a removal
order (CLAUDE.md 3.10).
